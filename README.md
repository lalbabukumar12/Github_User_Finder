🚀 GitHub User Finder

A sleek and interactive web application that allows users to search for any GitHub profile and view detailed information including repositories, followers, and more.

🌐 Live Demo  https://lalbabukumar12.github.io/Github_User_Finder/

📌 Features
🔍 Search any GitHub user by username
👤 View profile details (name, bio, location, join date)
📊 Display followers, following, and repositories
📁 Show latest repositories with:
Description
Language
Stars ⭐
Forks 🍴
⚡ Fast and responsive UI
❌ Error handling for invalid users
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
API: GitHub REST API
Styling: Custom CSS

⚙️ Installation & Setup
Clone the repository
git clone https://github.com/your-username/github-user-finder.git
-> Navigate to project folder
cd github-user-finder
-> Open index.html in your browser
🔧 How It Works
User enters a GitHub username
App fetches data using:
https://api.github.com/users/{username}
Displays:
Profile info
Repository list
Uses DOM manipulation to update UI dynamically
🎯 Project Purpose

This project demonstrates:

API integration
Async JavaScript (fetch, async/await)
DOM manipulation
Responsive UI design
